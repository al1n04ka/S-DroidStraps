# S-DroidStraps

<p align="center">
  <img src="icon-512.png" width="160" alt="S-DroidStraps">
</p>

A small, open-source FastFlag launcher for Roblox on Android. It writes
`ClientAppSettings.json` through **Shizuku** (wireless ADB) or **root** — no
client modification, no APK repacking, nothing patched.

## Features

- Minimal dark UI with four screens: Home, Flags, Helper, More.
- One-tap launch: writes the profile, stops Roblox, opens the client.
- Flag profiles with presets (Default, Performance, Experimental, FPS caps 60–144).
- Add, remove and edit flags; **import JSON** (merge or replace) and **export JSON**
  through the Android share sheet.
- Every flag in the profile is written to the file, including names outside
  Roblox's official allowlist (see the note below).
- Guided Shizuku setup plus a copyable one-line ADB command for PC users.
- Works without root; root (Magisk/Sui) additionally writes to the app's private
  `ClientSettings` path.

## Requirements

- Android 8.0+ (API 26), `minSdk 26`, `targetSdk 37`.
- [Shizuku](https://shizuku.rikka.app/) running with access granted, **or** root.

## How it works

1. The app stores flags in SharedPreferences and serializes them to JSON.
2. Through Shizuku (or root) it writes the file to
   `/data/local/tmp/ClientAppSettings.json`, `chmod 644`, then runs
   `am force-stop com.roblox.client`.
3. Roblox reads the file on its next start.

With root the same JSON is also copied to
`/data/data/com.roblox.client/files/exe/ClientSettings/ClientAppSettings.json`.

### A note on the FastFlag allowlist

Since September 2025 Roblox only honors locally configured flags from its
[official allowlist](https://devforum.roblox.com/t/allowlist-for-local-client-configuration-via-fast-flags/3966569).
This app still writes every flag you add, but the client silently ignores names
outside the list. That check happens inside the Roblox client — no launcher can
disable it, and this project does not try to.

## Build

Requirements: JDK 17+ (tested with 25) and Android SDK with API 37.1.

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat :app:assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`.

The launcher icon is generated by `tools/make-icon.ps1` (Windows, System.Drawing).
